# Elbow measurements

Following a complex fracture of the distal humerus, an open reduction internal fixation (ORIF) procedure was carried out.

Range of Motion (ROM) of the elbow has since been compromised, and daily measurements of ROM have been taken to monitor progress.
Measurememts are made with a simple wooden goniometer and protractor.

A subsequent open arthrolysis procedure was carried out in order to improve mobility.
Two of the four original screws were also removed.

The script `elbow.py` generates a plot that shows the ROM across time, as well as the arc (ROM<sub>max</sub> - ROM<sub>min</sub>).

Note a fully stright arm is 0°, a fully bent arm is ~150°.
